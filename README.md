# RESCUE-NET 2099 - Autonomous Food Rescue & Donation Platform

> **Futuristic Web Platform** for emergency surplus food rescue and redistribution, connecting donors, NGOs, shelters, and volunteer couriers.

## 🚀 Live GitHub Pages Deployment Guide

This project is fully structured and pre-configured for instant deployment to **GitHub Pages**.

### Steps to Deploy on GitHub Pages:

1. **Push your code to GitHub**:
   ```bash
   git add .
   git commit -m "Deploy RESCUE-NET 2099 platform"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   git push -u origin main
   ```

2. **Enable GitHub Pages**:
   - Go to your repository settings on GitHub (`Settings` -> `Pages`).
   - Under **Build and deployment** -> **Source**, choose **Deploy from a branch**.
   - Select **Branch**: `main` and **Folder**: `/ (root)`.
   - Click **Save**.

3. **View your site**:
   - Your live site will be available in 1-2 minutes at `https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/`.

## ✨ Features Included

- 🌌 **Futuristic Cyberpunk HUD**: Glowing glassmorphism UI, Orbitron typography, scanlines, and animated canvas background.
- ⚡ **Navigation Bar**: Quick tab switching, audio FX toggle, notification bell center, dynamic role selector, and SOS dispatch trigger.
- 🚨 **SOS Emergency Beacon Protocol**: Fullscreen warning banner, high-priority notification push, modal dispatch, and pulsing map alerts.
- 🔔 **Pop-up Notifications**: Live toast notification engine with sound synthesized audio alerts.
- 🗺️ **Tactical Satellite Radar**: Interactive Leaflet dark-mode map with glowing donor, NGO, courier, and SOS markers.
- ⏱️ **Real-Time Expiry Watchlist**: Dynamic ticking countdown timers for perishable surplus food.
- 🛡️ **Role-Based Action Engine**: Toggle between Donor, NGO / Shelter, Volunteer Courier, and Central Admin roles.
